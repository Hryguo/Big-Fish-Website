# Big Fish Chinese Cafe Website

Website for Big Fish Chinese Cafe, a family-owned restaurant in San Jose, CA.

Live site: https://bigfishchinesecafe.com

## Features
- Menu with photos, plus full PDF menu
- Online ordering (Clover)
- Click-to-call phone numbers
- Hours, location, Google Maps link
- Catering info
- Rotating promo banner, video popup for specials
- Links to Yelp, Google, Instagram, Facebook, Nextdoor
- Mobile-friendly layout

## Tech
- HTML, CSS, JavaScript (no framework)
- GitHub Pages + custom domain
- Basic SEO: sitemap, robots.txt, structured data

## Updates
- Kept up to date with new specials and menu changes since March 2026
